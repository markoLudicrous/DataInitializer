DataInitializer.

Primair gaat het om een geautomatiseerde database script om tabellen etc. aan te maken. 
De connectie naar de database zelf moet er al wel zijn.
Een bestaande project aangepast om lokaal uit te voeren en te verifiëren of het correct functioneert op lokale laptop.
In de PostgreSQL database moet vooraf wel een user met rechten en het schema zijn aangemaakt.
